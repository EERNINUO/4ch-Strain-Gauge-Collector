## 1. 板卡概述
- 功能定位：4通道应变信号同步采集，经调理后由MCU内置ADC采集，通过USB上传。
- 关键性能指标：
  - 采样率：每通道最大 1 Msps（12位）
  - 输入范围：±10mV（应变满量程）→ 经 4 倍放大 → 1/4 衰减 → ±10mV 进入滤波器 → ADC 输入 ±2.5V
  - 滤波器截止频率：100kHz 或 200kHz（4阶巴特沃斯）
  - 触发响应延迟：< 1μs（硬件触发 + 中断）
- 主要接口：
  - 电源输入：USB Type-B (5V)
  - 数据接口：USB 虚拟串口
  - 调试接口：SWD (4-pin)
  - 外部触发：SMA 接口
  - 4 通道应变输入：端子排或 RJ-50（参考 NI-9237）

## 2. 模块详细设计

### 2.2 模拟前端

#### 2.2.1 仪表放大器（预放大 4 倍）
- **原理图截图**：![仪表放大器](/docs/pic/仪表放大器原理图.png)
- **功能描述**：将应变片半桥的差分毫伏信号放大 4 倍，提高信噪比。
- **关键器件**：
  
| 器件 | 型号 | 特性 | 选型理由 |
|------|-----|------|---------|
| 仪表放大器 | INA828 | 低噪声、高共模抑制比、可进行直流偏置 | 性能满足需求，可进行直流偏置 |
| 模拟开关 | ADG619 | 双电源、高开关速度、低导通电阻、低漏电流 | - |

- **设计计算**：
  - R_G计算：由数据手册可知：$G = 1 + \frac{50 k\Omega}{R_G}$，$G=4$，则 $R_G = \frac{50}{G - 1} \approx 16.7 k\Omega$
  - 输出信号：由数据手册可知 $V_O = G(V_{IN+} - V_{IN-}) + V_{REF}$，则输出电压 $V_O$ 的共模分量 $V_{DC} = V_{REF}$，差模分量 $V_{AC} = G(V_{IN+} - V_{IN-})$
- **接口信号**：
  | 信号名 | 方向 | 连接到 | 备注 |
  |--------|------|--------|------|
  | INA_IN+, INA_IN- | 输入 | 应变半桥输出 | 差分 |
  | INA_OUT | 输出 | 衰减级输入 | 单端 |
  | SW_Ctrl | 输入 | 桥路切换信号 | - |

#### 2.2.3 差分转单端/衰减级
- **原理图截图**：![差分转单端-衰减原理图](pic/差分转单端-衰减原理图.png)
- **功能描述**：将预放大后的信号衰减至适合 ADC 输入的差分信号与幅度。
- **关键器件**：
  
  | 器件 | 型号 | 特性 | 选型理由 |
  |------|-----|------|---------|
  | 运算放大器 | OPA2192 | 高增益、低噪声、低功耗 | - |
  | 电阻 | - | 0.1% 精密电阻 | - |
- **设计计算**：
设滤波器输出单端信号为 $V_{in}$，ADC要求的差分输入为 $V_{diff} = V_{in}/4$。为保持输出共模电平稳定在 $V_{cm}=1.65\text{V}$，令同相支路输出 $V_{out+} = V_{cm} + V_{in}/8$，反相支路输出 $V_{out-} = V_{cm} - V_{in}/8$。由此，差分输出 $V_{out+} - V_{out-} = V_{in}/4$，满足设计要求。
同相支路采用电阻分压加电压跟随器实现增益 $+1/8$；反相支路采用反相比例衰减器实现增益 $-1/8$。两路输出均以 $1.25\text{V}$ 为共模参考，由电阻分压网络从 $V_{REF}$ 电源获得。
- **仿真结果**：
  ![差分转单端仿真波形](/docs/pic/差分转单端仿真波形.png)

### 2.2 MCU 最小系统（STM32G473）
- **原理图截图**：![MCU](./pic/E4_MCU.png)
- **功能描述**：核心控制与数据采集。
- **关键器件**：STM32G473VE，8MHz 晶振，复位电路，SWD 接口。

| 器件 | 型号 | 特性 | 选型理由 |
|------|-----|------|---------|
| MCU | STM32G473QET6 | ARM Cortex-M4F, 512KB Flash, 128KB RAM，丰富的模拟外设 | 性能满足需求，成本合理 |

- **具体设计**：
  - 电源：VDD 各引脚就近 100nF 电容，VDDA 独立 1μF+100nF。
  - 时钟：HSE 24MHz 晶振（10pF 负载电容）。
  - 调试接口：SWD（SWCLK, SWDIO） + NRST。
  - BOOT0 通过 10k 下拉，按键上拉可选。
  - UART：TX 经过开漏缓冲器接入总线；RX 上拉到 3.3V。
  
- **接口信号**：

| GPIO | 输出 | GPIO | 模拟开关 | 全桥-半桥切换 |
| UART | 双向 | UART(115200) | USB Type-A | 外部触发，多机同步 |
| QSPI | 双向 | QSPI | Flash | 存储程序与校准参数 |
| FMC | 双向 | FMC  | SRAM | 高速数据缓存 |
| ADC | 输入 | ADC | 模拟前端输出 | 4通道差分输入 |

### 2.3 USB 接口
- **原理图截图**：![USB](./pic/E4_USB.png)
- **功能描述**：虚拟串口（CDC）通信。
- **关键器件**：

| 器件 | 型号 | 特性 | 选型理由 |
|------|-----|------|---------|
| USB 接口 | 双层 USB Type-A | 4线母头 USB2.0 | 连接稳定，可靠性高，行业标准 |

## 3. PCB 布局与布线指南

### 3.1 层叠结构
- 层数：4 层
  - Top：信号 + 局部电源
  - Inner1：完整地平面（GND）
  - Inner2：电源分割（3.3V_D, 3.3V_A，±4V_A, 1.8V_A, 2.5V）
  - Bottom：信号 + 地铜
> 此处采用四层板是因为题目要求使用四层板进行设计，但考虑到 SRAM 的布线复杂度及高速下参考平面的切换问题，实际设计中推荐采用六层板或更多

### 3.2 整体布局原则
1. 按功能分区：模拟前端（左） → MCU（中） → 接口（右），符合信号流向。
2. 模拟区与数字区物理隔离，地平面不分割。
3. 电源转换（LDO）靠近输入接口，输出电容紧贴 LDO。
4. 晶振靠近 MCU，下方不走线。

### 3.3 关键模块布线约束

| 模块 | 约束 | 
|------|------|
| 模拟差分信号（传感器输入、ADC 差分输入） | 等长、紧耦合，阻抗 100Ω，周围包地 |
| USB DP/DM | 90Ω 差分阻抗，等长误差 < 1mm |
| QSPI 四线 | 各自长度匹配（误差 < 5mm） |
| SRAM 地址/数据 | 组内等长误差 < 100mil，组间等长误差 < 300mil ，组间保持间距 |
| SRAM 控制线 | 等长，紧耦合，阻抗 100Ω，周围包地 |
| 触发输入 | 走线短，远离高频数字信号 |
| 电源 | 模拟 3.3V 与数字 3.3V 单点连接（0Ω 电阻或磁珠） |
> ST 应用笔记指出，在 FMC 走线长度 < 120mm 时，可以不考虑阻抗匹配与端接。

### 3.4 地平面与电源完整性
- 完整地平面（Inner1），所有信号参考该层。
- 模拟电源区域在内层分割，与数字电源层分开，但在输入端通过磁珠单点汇合。
- 每个 IC 电源引脚放置 0.1μF 电容，大电容（10μF）分布于电源入口及 SRAM 附近。

### 3.5 测试点设计
- 各电压轨（3.3V_D, 3.3V_A, 1.8V_A, 2.5V, 1.25V等）
- 关键模拟节点（INA_OUT, FILTER_OUT, D1Q±）
- 关键数字信号（USB，UART，QSPI）
- 测试点形式：直径 1mm 圆形露铜，加过孔。

## 4. 测试与调试计划

### 4.1 上电前检查
- 电源对地短路测试
- 极性检查（电容、二极管、LDO）
- 焊接完整性（尤其 QFN 封装）

### 4.2 分步调试
1. **电源**：焊好 LDO 后测各电压轨空载纹波。
2. **MCU 最小系统**：焊 MCU、晶振、复位、SWD，烧录点灯代码。
3. **存储**：测试 QSPI Flash 读写，SRAM 读写。
4. **USB**：枚举虚拟串口，回环测试。
5. **触发**：输入脉冲，MCU 中断响应。
6. **模拟前端**：输入已知直流电压，逐级测量放大器输出，验证增益与滤波。
7. **全链路**：输入模拟应变信号（函数发生器 + 电阻分压模拟电桥），采集数据上传，验证线性度。

### 4.3 关键波形测试点
- 滤波截止频率（扫频输入，测输出 -3dB 点）
- ADC 采样抖动（固定直流，观察码值跳动）
- 触发延迟（示波器同时测触发输入和 ADC 采样完成信号）
